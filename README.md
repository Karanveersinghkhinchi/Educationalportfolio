# Smart Study Portfolio

A clean Vite + React project version of your Smart Study school portfolio.

## Run in VS Code

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Where to edit

- `src/data/videos.js` → change videos, thumbnails, titles, descriptions, Vimeo IDs
- `src/components/HomePage.jsx` → homepage sections
- `src/components/ContactPage.jsx` → contact details and form layout
- `src/components/ProcessPage.jsx` → process cards
- `src/styles/global.css` → full styling
- `src/App.jsx` → page routing logic

## Notes

- This is a single-page React app with internal page switching using state.
- If you want, this can later be upgraded to React Router, Tailwind, Framer Motion, or a CMS-based setup.
